# OpenSwitch

Свободный (GPL-3.0) автоматический переключатель раскладки **EN ⇄ RU / UA** для Windows, написанный на Rust.
Аналог Punto Switcher: набрали `ghbdtn` — после пробела получите `привет`, а раскладка сама переключится на русскую.

- не просто исправляет текст, а **переключает раскладку** — следующее слово вы уже пишете на нужном языке;
- удобное окно настроек (правый клик по значку → «Настройки…»);
- один `.exe` (~7 МБ), без установки, без интернета, без телеметрии;
- словари и языковая модель встроены в программу;
- значок в трее показывает текущую раскладку (EN синий / RU красный, серый — автопереключение выключено).

## Горячие клавиши (по умолчанию)

| Клавиши | Действие |
|---|---|
| **Pause** | исправить последнее слово (нажать ещё раз — вернуть обратно) |
| **Shift, Shift** (быстро дважды) | то же самое — для ноутбуков без Pause |
| **Shift+Pause** | исправить раскладку выделенного текста |
| **Alt+Pause** | включить/выключить автопереключение |
| клик по значку в трее | включить/выключить автопереключение |
| правый клик по значку | меню: **Настройки…**, автозапуск, выход |

Если вы отменили автоисправление клавишей Pause, слово запоминается и больше не исправляется
(список — в `exceptions.txt`). **Backspace** сразу после автоисправления тоже возвращает слово как было;
если отменить так одно и то же слово дважды, оно тоже попадёт в исключения.

Ещё OpenSwitch:
- исправляет случайно включённый CapsLock: `пРИВЕТ` → `Привет` (и выключает CapsLock);
- не трогает ссылки, почту, имена файлов и `camelCase` (`github.com`, `readme.md`, `getValue`);
- осторожнее с первым словом после того, как вы сами переключили раскладку — чтобы не «исправить»
  английское слово, которое вы специально набрали посреди русского текста.

Всё это включается и выключается в настройках.

## Настройки

Правый клик по значку в трее → **«Настройки…»** (или `openswitch.exe --settings`).
Все настройки — на одной прокручиваемой странице; меню слева показывает, где вы находитесь,
и переносит к нужному разделу, а поиск над ним оставляет только подходящие пункты:

- **Основные** — автоисправление, насколько смело исправлять (осторожно / обычно / смело),
  автозапуск с Windows, поле для проверки; в «Тонкой настройке» — проверка на Enter,
  однобуквенные слова и точная чувствительность;
- **Клавиши** — нажмите на кнопку и затем нужное сочетание; двойной Shift;
- **Программы** — где не исправлять автоматически (можно выбрать из открытых окон);
- **Слова** — слова, которые никогда не исправляются;
- **О программе** — журнал для сообщений об ошибках и сброс настроек.

Кнопки «Сохранить» нет: изменения применяются сразу. Сами файлы лежат в `%APPDATA%\OpenSwitch\`
(`settings.ini`, `exceptions.txt`); если поправить их вручную, программа заметит это сама.

Язык интерфейса — вкладка «Основные»: как в Windows, English, Русский или Українська.
Он же относится к меню значка в трее и окну «О программе».

Журнал работы — `%LOCALAPPDATA%\OpenSwitch\logs\openswitch.log`. Он нужен для сообщений об ошибках:
приложите его к issue. Набранный текст в журнал не записывается.

По умолчанию автопереключение отключено в терминалах (cmd, PowerShell, Windows Terminal, PuTTY) и
менеджерах паролей KeePass/KeePassXC; ручное исправление там работает. Если программируете — добавьте
свой редактор (например `code.exe`) на вкладке «Программы».

## Сборка

Нужен Rust (https://rustup.rs). В папке проекта:

```
cargo build --release
```

Готовый файл: `target\release\openswitch.exe`. Тесты (работают и на Linux): `cargo test`.

Оценка точности детектора на реальной частотности слов:

```
pip install wordfreq
python tools/gen_data.py          # пересобрать словари и модель в data/
cargo run --release --example eval -- <список_en.txt> <список_ru.txt>
```

## Как это работает

1. Глобальный низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`) запоминает **физические клавиши**
   текущего слова (а не символы), поэтому слово можно «перерисовать» в любой раскладке.
2. На пробеле/Enter слово отрисовывается в обеих раскладках и сравнивается
   (`src/detect.rs`):
   - по частотным словарям (60 000 слов на язык — английский, русский, украинский — из проекта `wordfreq`);
   - по символьной триграммной модели языка — для слов, которых нет в словаре;
   - с отдельными правилами для коротких и однобуквенных слов, аббревиатур (`USA`, `ФСБ`)
     и знаков, которые в английской раскладке внутри слова не встречаются (`j;bl'v` → `ожидэм`).
3. Если слово набрано не в той раскладке, программа стирает его (Backspace), печатает
   исправленный вариант через Unicode-ввод (`SendInput`) и переключает раскладку окна.
4. Переключение проверяется: через 0,3 с программа смотрит, сменилась ли раскладка на самом деле.
   Если окно проигнорировало запрос (так делают некоторые программы), OpenSwitch нажимает системное
   сочетание переключения (Alt+Shift, Ctrl+Shift или Win+Space — берётся из настроек Windows)
   и запоминает, что в этой программе так надо делать сразу.

Точность на 30 000 слов с реальной частотностью: ложные срабатывания ≈0,06–0,19 %,
находит ≈96 % слов, набранных не в той раскладке. Основные пропуски — пары, которые являются
настоящими словами в обоих языках (`here` ⇄ `руку`).

Внешние события ввода (автонабор менеджеров паролей, удалённые рабочие столы) игнорируются.

## Структура

```
src/layout.rs   таблицы «клавиша → символ» (встроенные и прочитанные из Windows), перекодировка текста
src/detect.rs   детектор «не та раскладка»
src/engine.rs   логика набора: буфер слова, горячие клавиши, двойной Shift (не зависит от Windows)
src/config.rs   settings.ini, разбор горячих клавиш
src/i18n.rs     переводы интерфейса: английский, русский, украинский
src/win.rs      Windows: хуки, SendInput, проверяемая смена раскладки, трей, буфер обмена
src/sys.rs      Windows: файлы настроек, автозапуск, раскладки, список программ
src/ui.rs       окно настроек (egui)
src/clipboard.rs  буфер обмена: снимок всех форматов и восстановление
src/logging.rs    журнал и обработка паник
assets/         иконка (SVG — исходник, .ico генерируется tools/gen_icons.py), манифест
build.rs        встраивает иконку, версию и манифест в exe
data/           словари и триграммные таблицы (генерируются tools/gen_data.py)
```

## Ограничения

- Пара раскладок: английская + кириллическая (русская, украинская или белорусская, в том числе
  изменённые, например украинская с добавленными русскими буквами — символы клавиш читаются
  из самой раскладки). Украинский словарь включается сам, когда используется украинская раскладка.
  Для белорусской пока используется русский словарь.
- Приложения, запущенные от администратора, не видят ввод от программы без прав администратора —
  запустите OpenSwitch от администратора, если нужно работать в них.
- Пароли в обычных полях не отличить от текста — для таких случаев есть Alt+Pause и список исключений.

# Ручная проверка OpenSwitch

Проверка на настоящей Windows перед выпуском. Отмечайте `[x]`, а что не так — пишите прямо
под пунктом: что сделали, что ожидали, что получилось. К сообщению приложите журнал
`%LOCALAPPDATA%\OpenSwitch\logs\openswitch.log` (набранный текст туда не пишется).

Подготовка: в Windows установлены минимум английская и русская раскладки (лучше ещё
украинская). Соберите свежий exe: `cargo build --release`, файл — `target\release\openswitch.exe`.
Закройте старый OpenSwitch (меню значка → «Выход»).

Чтобы проверить первый запуск «с нуля», переименуйте папку `%APPDATA%\OpenSwitch`
(например в `OpenSwitch.bak`), а после проверки верните.

## 1. Первый запуск

- [ ] Запуск exe: появился значок в трее и открылось окно первого запуска.
- [ ] В окне видно, что умеет программа и что с конфиденциальностью; выбор модулей работает.
- [ ] Поле «попробуйте»: `ghbdtn` и пробел превращается в «привет».
- [ ] Выключатель «Запускать с Windows» работает (проверьте в «Диспетчер задач → Автозагрузка»).
- [ ] «Пропустить» или закрытие окна: при следующем запуске окно само больше не открывается.
- [ ] «Настройки → О программе» снова открывает это руководство.

## 2. Значок в трее

- [ ] На значке видна текущая раскладка (EN / RU / UA) и она меняется вместе с раскладкой.
- [ ] Щелчок по значку включает и выключает автопереключение (значок это показывает).
- [ ] Меню: «Настройки…», «Автопереключение раскладки», «Запускать вместе с Windows», «О программе», «Выход».
- [ ] Повторный запуск exe при уже работающем OpenSwitch открывает настройки, а второго значка нет.
- [ ] После перезапуска Проводника (Диспетчер задач → Проводник → Перезапустить) значок вернулся.

## 3. Раскладка (основное)

Проверьте в Блокноте, в браузере (Chrome, Edge или Firefox) и в Telegram или Word.

- [ ] `ghbdtn` + пробел → «привет», раскладка переключилась на RU.
- [ ] `руддщ` + пробел → `hello`, раскладка переключилась на EN.
- [ ] С украинской раскладкой: `ghbdsn` + пробел → «привіт» (UA); `привыт` → `привіт`.
- [ ] Обычный правильный текст на английском, русском и украинском не трогается
      (наберите пару предложений).
- [ ] Enter тоже проверяет слово (если включено «Проверять слово и при нажатии Enter»).
- [ ] Однобуквенные: `d` → «в», `z` → «я».
- [ ] Ссылки, почта, имена файлов не трогаются: `github.com`, `mail@example.com`, `readme.md`, `getValue`.

## 4. Отмена и ручное исправление

- [ ] Backspace сразу после автоисправления возвращает слово как было набрано.
- [ ] То же слово, отменённое дважды, больше не исправляется (появилось в «Слова»).
- [ ] Pause исправляет последнее слово; повторный Pause — возвращает (с тремя раскладками —
      перебирает варианты по кругу).
- [ ] Двойной Shift делает то же, что Pause.
- [ ] Shift+Pause исправляет выделенный текст; содержимое буфера обмена после этого не пропало.
- [ ] Alt+Pause включает и выключает автопереключение.
- [ ] Слово, исправленное вручную, в следующий раз исправляется само («Слова → Всегда исправлять»).
- [ ] Первое слово после того, как вы сами переключили раскладку, не исправляется без явной причины.

## 5. Модуль «Текст»

- [ ] Заглавная буква в начале предложения: `привет. как дела` → «Привет. Как дела».
- [ ] Сокращения не считаются концом предложения: «т. е.», «ул.», «e.g.».
- [ ] Английское `i` → `I`; `iPhone` не трогается.
- [ ] Пробел перед знаком: `привет , как` → «привет, как».
- [ ] Случайный CapsLock: `пРИВЕТ` → «Привет», и CapsLock выключился.
- [ ] Backspace сразу после правки её отменяет.

## 6. Модуль «Орфография» (включите в настройках)

- [ ] `првиет` + пробел → «привет»; `freind` → `friend`; `Сегоддня` → «Сегодня».
- [ ] Опечатка и не та раскладка сразу: `ghdbtn` → «привет», `акуштв` → `friend`.
- [ ] Правильные редкие слова и имена не портятся (наберите несколько своих).
- [ ] Backspace отменяет исправление.
- [ ] Выключили модуль «Орфография» — опечатки больше не исправляются.

## 7. Модули целиком

- [ ] Выключили «Раскладку» — слова не переключаются, горячие клавиши не работают,
      её настройки в окне скрыты.
- [ ] Выключили «Текст» — заглавные буквы и CapsLock не трогаются.
- [ ] Включили обратно — всё работает без перезапуска.

## 8. Окно настроек

- [ ] Открывается из меню значка; меню слева подсвечивает текущий раздел при прокрутке.
- [ ] Поиск оставляет только подходящие пункты (попробуйте «пароль», «Shift», «admin»).
- [ ] Изменения применяются сразу (кнопки «Сохранить» нет), в окне видно «Изменения применены».
- [ ] Запись горячей клавиши: нажать на кнопку, потом сочетание; конфликт двух команд показан.
- [ ] Язык интерфейса: English / Русский / Українська — меняется окно и меню значка.
- [ ] «Программы»: добавить программу из открытых окон — по умолчанию «Только вручную»:
      слова не исправляются сами, а Pause работает.
- [ ] «Начинать с английской»: переход в программу (Alt+Tab) из окна с RU — раскладка стала EN;
      переход между окнами этой же программы раскладку не трогает.
- [ ] «Помнить раскладку»: ушли из программы с RU, в другой программе включили EN, вернулись —
      снова RU.
- [ ] «Выключено»: в программе не работает ничего, даже Pause.
- [ ] Правка `%APPDATA%\OpenSwitch\settings.ini` в Блокноте подхватывается без перезапуска.
- [ ] «Сбросить настройки» спрашивает подтверждение и сбрасывает.
- [ ] Тема окна: светлая, тёмная, как в Windows — меняется сразу, окно первого запуска тоже.
- [ ] «Звук при исправлении»: после автоисправления слышен тихий щелчок, не громкий и не резкий;
      при ручном исправлении (Pause) звука нет.
- [ ] «О программе → Экспорт…» сохраняет файл; на «чистых» настройках «Импорт…» возвращает
      настройки, слова-исключения и выученные слова.

## 9. Поля паролей

- [ ] Страница входа любого сайта в Chrome / Edge / Firefox: в поле пароля `ghbdtn` + пробел
      остаётся `ghbdtn`, Pause ничего не делает.
- [ ] В поле логина на той же странице исправление работает.
- [ ] Поле пароля в обычной программе Windows (например, ввод пароля Wi-Fi в старой «Панели
      управления» или вход в Telegram с облачным паролем) — тоже ничего не исправляется.
- [ ] Выключили «Программы → Ничего не делать в полях пароля» — в поле пароля снова исправляет.
- [ ] Браузер не стал заметно медленнее.

## 10. Запуск с правами администратора

- [ ] Без этой опции: Блокнот, запущенный от администратора, — слова не исправляются
      (так и должно быть).
- [ ] «Основные → Запускать с правами администратора»: Windows один раз спросила разрешение,
      значок в трее перезапустился, в окне «Изменения применены».
- [ ] Теперь в Блокноте от администратора `ghbdtn` → «привет».
- [ ] В журнале есть строка `administrator rights: true`.
- [ ] «Запускать с Windows» в окне и «Запускать вместе с Windows» в меню значка — отмечены и недоступны.
- [ ] В Планировщике заданий есть задача «OpenSwitch» (при входе в систему, наивысшие права).
- [ ] Выйти из Windows и войти снова: OpenSwitch запустился сам, без вопроса UAC.
- [ ] Запуск exe вручную тоже не спрашивает UAC (и не создаёт второй значок).
- [ ] Окно настроек, открытое вручную (`openswitch.exe --settings`), применяет изменения.
- [ ] Отказ в окне UAC: опция осталась выключенной, в окне «Windows не дала разрешения».
- [ ] Выключить опцию: задача исчезла из Планировщика, значок перезапустился без прав
      администратора, «Запускать с Windows» снова доступен.

## 11. Разное

- [ ] Win+L и вход обратно: Shift / Ctrl не «залипают», исправление работает.
- [ ] Новая раскладка, добавленная в Windows при работающем OpenSwitch, подхватывается.
- [ ] Игра или полноэкранная программа: ввод не тормозит.
- [ ] Набор быстрым темпом (несколько слов подряд) не теряет и не переставляет буквы.
- [ ] «Выход» из меню убирает значок; процесса `openswitch.exe` в Диспетчере задач не осталось.

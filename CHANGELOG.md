# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.1] - 2026-11-18

### Исправлено
- «Исправить выделенный текст» больше не портит буфер обмена: сохраняются и возвращаются все форматы
  (картинки, файлы, HTML, RTF), а не только текст. Если буфер был пуст, он остаётся пустым.
  Возвращённое содержимое не дублируется в истории буфера обмена Windows (Win+V).
- Перехватчик клавиатуры больше не открывает чужие процессы и не пишет файлы внутри хука —
  Windows не будет снимать его из-за медленного ответа. Название программы определяется
  по событию смены окна (`SetWinEventHook`).
- Ошибка внутри обработчика клавиши больше не роняет программу: клавиша просто пропускается
  дальше, а ошибка записывается в лог.
- Окно настроек показывает понятное сообщение, если видеодрайвер не поддерживает OpenGL 2
  (виртуальные машины, RDP), вместо того чтобы молча закрыться.

### Добавлено
- Журнал работы: `%LOCALAPPDATA%\OpenSwitch\logs\openswitch.log` (ротация по 1 МБ).
  Набранный текст в журнал никогда не попадает.
- Иконка приложения, сведения о версии (Свойства → Подробно) и манифест в exe:
  чёткое отображение на мониторах с масштабированием (Per-Monitor V2), современный вид диалогов.
- CI: проверка форматирования, `clippy -D warnings` и тесты на Linux и Windows;
  в релизе — zip-архив, `SHA256SUMS.txt` и аттестация происхождения сборки.

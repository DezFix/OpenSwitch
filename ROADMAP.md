# OpenSwitch — план до 1.0

Принципы продукта:
- **без ИИ** — только словари, правила и статистика; всё работает без интернета, набранный текст
  никуда не уходит и не пишется в журнал;
- **модули** — каждая группа функций (Раскладка, Текст, Орфография, будущие) в своём файле кода,
  со своим выключателем; пользователь сам решает, что включить;
- **всё настраивается в окне**, а не в файлах: каждая опция — в окне настроек, с поиском и
  переводом (EN/RU/UK); `settings.ini` — только хранилище;
- **осторожность важнее охвата**: лучше пропустить исправление, чем испортить правильное слово;
  пороги подбираются замером (`examples/eval*.rs`), любое исправление отменяет Backspace.

Работа идёт в ветке `dev-0.4`; в `main` попадают выпуски.

      изменения применяются сразу, запись горячих клавиш нажатием.

- [x] **Помощь с текстом**: заглавная буква в начале предложения (сокращения учтены), `i` → `I`,
      пробел перед `, . ! ?`.

      «Раскладки»; ручное исправление перебирает варианты по кругу.
- [x] **Модули** «Раскладка», «Текст», «Орфография» с выключателями.
- [x] **Орфография** по словарям: только однозначные случаи (уверенность ≥ 85 %), окончания не
      трогает.
- [x] **Окно первого запуска** с руководством и выбором модулей.

## После 1.0 (идеи)

- Автозамена и сниппеты (`;адрес` → полный адрес).
- Для выделенного текста: транслит, смена регистра.
- Больше языков: свой словарь для белорусского, казахский, пары EN+DE / EN+PL.
- Portable-режим (настройки рядом с exe).
- Окно настроек на RDP и в виртуальных машинах без OpenGL 2: `wgpu` (DX12 / программный WARP)
  вместо `glow`. Сейчас в этом случае показывается сообщение и путь к `settings.ini`.
- Порт на macOS (движок и детектор не зависят от Windows).

  качественно не сделать.
- Любой ИИ, облако, телеметрия.
